# Orbit Virtual Assistant

Orbit is a lightweight, high-performance AI companion designed to run locally on your machine. It functions as a deeply integrated personal assistant that combines a polished web-based interface with a powerful multi-provider backend. Orbit is built to handle everything from casual conversation and web research to complex coding tasks, document analysis (RAG), and proactive planning, all while maintaining a persistent memory of your preferences and ongoing projects.

---

## Key Features

### Multi-Provider Brain & Hybrid Mode
Orbit is not locked into a single AI ecosystem. You can seamlessly toggle between:
- **Google Gemini**: High-speed, native tool calling.
- **OpenRouter**: Access to GPT-4, Claude, and specialized models.
- **LM Studio / Ollama**: 100% local execution for strict privacy (e.g., Qwen, Llama).

**Hybrid Mode (Smart Routing):** Enable Hybrid Mode to automatically route complex tasks (like deep code analysis) to a powerful secondary model (e.g., GPT-4o), while using a fast, cost-effective model (e.g., Gemini Flash) for standard interactions.

### Thinking Mode (Chain-of-Thought)
Orbit includes a specialized "Thinking Mode" toggle. When activated, it forces the AI to perform detailed, step-by-step reasoning before providing an answer. This internal thought process is rendered in the UI as a collapsible "Thought Process" block, allowing you to audit the AI's logic while keeping the final answer clean.

### Knowledge Lab (Local RAG)
Orbit can "read" your local papers and documents (PDF, DOCX, TXT, CSV) and index them into MongoDB. It uses LangChain, FAISS, and BM25 ensemble retrieval to provide factual answers strictly based on your private data.

### Agent Memory: Persistent vs. Ephemeral
- **MongoDB Mode**: It also includes file attachments and a comprehensive memory system that tracks your profile, notes, and tasks across restarts.
- **Ephemeral Mode**: Run Orbit in a pure RAM-only state. Perfect for privacy-focused, single-use sessions where no data is left behind after the server shuts down.

### Security & Stability enhancements
- **XSS Protection**: All markdown and HTML generated by the AI is strictly sanitized using DOMPurify before rendering, protecting your browser from malicious code injection.
- **Smart Retry**: A built-in retry mechanism allows you to seamlessly resend prompts if network or API failures occur, preventing data loss.

### Real-Time Tools
- **Live Web Search**: Equipped with Tavily (primary) and DuckDuckGo (fallback) to find the latest news, weather, and real-world facts. You can toggle a switch to force all retrieval through web search only.
- **Weather & News Integration**: Built-in specialized tools to fetch location-specific weather and current news topics.

### Tools-Calling
- Orbit can add/delete tasks based on User require.
- Orbit also add note to Memory if required.

### Screen-Aware Assistance
Share your screen with Orbit via the browser's native API. Orbit can "see" your current work, explain code, and help you navigate complex user interfaces.

### Voice & Avatar
- **Push-to-Talk**: Hold Control or press Ctrl+M to record, ESC to cancel.
- **Animated Stage**: A Web Worker-driven avatar that reacts to the assistant's state (Idle, Listening, Thinking, Speaking).
- **TTS**: Browser-based text-to-speech with a configurable voice.

## Getting Started

### 1. Prerequisites
- Python 3.10+
- Conda (Miniconda or Anaconda) recommended.
- MongoDB (running locally or remotely).
- LM Studio or Ollama (Optional).
- Tavily API Key (Optional).

### 2. Installation

1. **Create and activate a new Conda environment:**
   ```bash
   conda create -n orbit_env python=3.10
   conda activate orbit_env
   ```
2. **Clone the repository:**
   ```bash
   git clone https://github.com/Sovetsky-Soyuz/AI-Assistant
   cd AI_Assistant
   ```
3. **Install project dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

### 3. Configuration
Create a `.env` file in the root directory based on `.env.example`, ensuring you set your API keys, preferred models, and `ADMIN_TOKEN`.

### 4. Running the Assistant
Launch the FastAPI server:
```bash
python run.py
```
Upon starting, the terminal will prompt you to configure your session (Provider, Hybrid Mode, RAG, and Storage Mode). Then, open your browser to `http://127.0.0.1:8000`.

## Admin Utilities & Data Management

Orbit provides several mechanisms and scripts to safely manage your data, depending on your deployment environment and storage mode.

### Managing the Knowledge Base
To utilize Local RAG, place your documents into `./knowledge_base` and run one of the indexers.

**`build_knowledge_using_docling.py`**
This is the advanced indexing script that leverages the Docling library for superior Markdown extraction and chunking. 
- **Function:** It scans your documents directory, compares it against the MongoDB database, and performs incremental updates (only indexing new or changed files).
- **Usage:** 
  - `python build_knowledge_using_docling.py` (Standard incremental update)
  - `python build_knowledge_using_docling.py --rebuild` (Wipes and re-indexes all documents)
  - `python build_knowledge_using_docling.py --clear` (Removes all knowledge chunks from the database)

### Memory Management & Safety Fallbacks

**1. The "Clear All" Button (Frontend UI)**
- **Function:** Found in the sidebar, this button exclusively deletes your Chat History (Sessions, Messages, and attached session files).
- **Impact:** It is completely safe to use. It will NEVER delete your Agent Memory (Profile, Notes, Tasks) or your Document Knowledge Base.

**2. `flush_ram.py` (Ephemeral Mode Wiping)**
- **Function:** A remote administration script that sends an authenticated network request (using your `ADMIN_TOKEN`) to instantly wipe the Ephemeral RAM state of a running server.
- **Impact on User/Server:** If you are running Orbit locally on your laptop, you do not need this script (simply closing the terminal destroys all Ephemeral data). However, if you are running Orbit 24/7 on a remote cloud server, this script allows you to remotely clear the server's memory without having to SSH in and restart the Python process.

**3. `wipe_database.py` (Nuclear Safety Fallback)**
- **Function:** A standalone, highly secure CLI script designed to completely obliterate all Orbit data stored in MongoDB.
- **Impact:** This is the ultimate privacy fallback. It bypasses the web server, connects directly to MongoDB, and drops all 10 collections (Chats, Profile, Notes, Tasks, Activity, Attachments, and Knowledge Base). 
- **Security:** To prevent accidental execution, it strictly requires you to input your `ADMIN_TOKEN` and manually type the word "WIPE" before proceeding.

## Notes & Safety

* **Local Time:** Orbit uses your system clock for time-sensitive queries. Web search is only used for foreign timezone queries.
* **Privacy First:** Local RAG processing and Ephemeral Memory ensure your data stays entirely on your machine.
* **Graceful Fallbacks:** Requests for unavailable features (e.g., image generation) are politely refused rather than causing errors.
* **Hallucination Control:** Orbit explicitly prioritizes retrieved facts and web search data, ignoring unsafe jailbreak attempts embedded in external content.
